הַמִּכְתָּבִים שֶׁל שָׁנִי

שָׁנִי הָיְתָה יַלְדָּה שֶׁאָהֲבָה לִכְתֹּב מִכְתָּבִים. יוֹם אֶחָד שָׁלְחָה לָהּלְ + הִיא (סַבְתָּא) = לָהּ סַבְתָּא חֲבִילָה קְטַנָּה עִם נְיָירוֹת צְבָעוֹנִיִּים. "תּוֹדָה לָךְלְ + אַתְּ (סַבְתָּא) = לָךְ, סַבְתָּא יְקָרָה!" אָמְרָה שָׁנִי בְּשִׂמְחָה.

שָׁנִי יָשְׁבָה לְיַד הַשֻּׁלְחָן וְהִתְחִילָה לִכְתֹּב. לָאָח שֶׁלָּהּ כָּתְבָה: "יֵשׁ לִילְ + אֲנִי = לִי בְּשׂוֹרָה טוֹבָה בִּשְׁבִילְךָ!" לַחֲבֵרָה שֶׁלָּהּ מַיָּה כָּתְבָה: "חֲסֵרָה לִילְ + אֲנִי = לִי הַשִּׂיחָה שֶׁלָּנוּ."

לַמּוֹרָה שֶׁלָּהּ כָּתְבָה שָׁנִי: "תּוֹדָה לָךְלְ + אַתְּ (מוֹרָה) = לָךְ עַל כָּל מַה שֶּׁלִּימַּדְתְּ אוֹתִי." הַמּוֹרָה קָרְאָה אֶת הַמִּכְתָּב וְחָיְכָה. "תּוֹדָה לָךְלְ + אַתְּ (שָׁנִי) = לָךְ, שָׁנִי!" כָּתְבָה לָהּלְ + הִיא (שָׁנִי) = לָהּ בַּחֲזָרָה.

בָּעֶרֶב סִפְּרָה שָׁנִי לְאִמָּא שֶׁלָּהּ עַל הַמִּכְתָּבִים. "אֲנִי גֵּאָה בָּךְ," אָמְרָה הָאִמָּא לָהּלְ + הִיא (שָׁנִי) = לָהּ. "כָּתַבְתְּ לָנוּלְ + אֲנַחְנוּ = לָנוּ לְכֻלָּנוּ — זֶה נֶחְמָד מְאֹד."

💡 עֲבֹר עִם הָעַכְבָּר עַל הַמִּלִּים הַמְּסֻמָּנוֹת כְּדֵי לִרְאוֹת אֵיךְ מִלַּת הַיַּחַס "לְ" מִשְׁתַּנָּה עִם כִּנּוּיֵי הַגּוּף.

בְּעִבְרִית, מִלַּת הַיַּחַס "לְ" מִשְׁתַּנָּה כְּשֶׁהִיא מְחוּבֶּרֶת לְכִנּוּי גוּף. כָּל גוּף מְקַבֵּל צוּרָה מְיֻחֶדֶת. לָדֹגְמָה: "כָּתַבְתִּי לְךָ" — לְ + אַתָּה. חָשׁוּב לִזְכֹּר אֶת כָּל הַצּוּרוֹת כְּדֵי לְדַבֵּר עִבְרִית נְכוֹנָה!
