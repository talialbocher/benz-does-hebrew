# תהליך יצירת שיעור חדש — מדריך עבודה

המטרה: שיעורים עקביים, נכונים פדגוגית וללא שגיאות, שמקדמים את בן לרמת כיתה ד׳.
העיקרון: **שלבים נפרדים, כל שלב עם "עיניים טריות"** — לא סוכן לכל קטע בשיעור,
אלא סוכן יוצר אחד + סוכן מגיה נפרד + בדיקה אוטומטית.

## קבצי המערכת (בתיקייה `_system`)

| קובץ | תפקיד |
|------|--------|
| `curriculum.md` | מפת הנושאים — מה כוסה ומה הבא בתור |
| `ben_progress.md` | מעקב אישי — איפה בן חזק ואיפה צריך חיזוק |
| `lesson_template.html` | תבנית קבועה: עיצוב, מבנה, מנוע משחקים, מטלת כתיבה |
| `proofread_checklist.md` | צ׳ק-ליסט לסוכן ההגהה |
| `verify_lesson.py` | בדיקה טכנית אוטומטית |

## השלבים

### שלב 1 — בחירת נושא (דקה)
פתחו את `curriculum.md` ואת `ben_progress.md`. בחרו:
- נושא חדש מחלק ב של תכנית הלימודים, **או**
- שיעור חזרה לנושא שמסומן 🔁 (דורש חיזוק).
כלל אצבע: על כל 3–4 נושאים חדשים — שיעור חזרה אחד.

### שלב 2 — יצירת השיעור (סוכן יוצר)
פרומפט מוכן (להעתיק לשיחה חדשה / לסוכן):

> צור שיעור עברית מספר NN בנושא [נושא] לפי התבנית
> `_system/lesson_template.html`. קרא קודם את `_system/curriculum.md`
> (להקשר ולרצף) ואת השיעור הקודם (לקישורי הניווט).
> דרישות: סיפור מקורי וקוהרנטי שכל השיעור נבנה סביבו (או שיר/קטע מוכר
> מחלק ג של תכנית הלימודים, מצוטט במדויק עם קרדיט); ניקוד מלא בכל טקסט
> עברי כולל בתוך JavaScript; פלטת צבעים ייחודית; סצנה ויזואלית מקורית לכל
> משחק (דרך onCorrectComp/onCorrectGram); קטע כתיבה אחד;
> 5–6 שאלות הבנה + 6 שאלות דקדוק; אסור להשאיר {{placeholders}}.
> שמור כ-`lessonNN_shem_beanglit.html` בתיקיית השורש.

חשוב: הסוכן היוצר כותב הכל יחד — הסיפור מכתיב את אוצר המילים, השאלות והמשחקים.

### שלב 3 — הגהה (סוכן נפרד, קונטקסט נקי!)
לפתוח שיחה חדשה או תת-סוכן שלא ראה את תהליך היצירה:

> אתה מגיה מומחה לעברית ולניקוד. עבור על הקובץ `lessonNN_*.html`
> לפי הצ׳ק-ליסט `_system/proofread_checklist.md`. בדוק **כל** טקסט עברי,
> כולל מחרוזות בתוך ה-JavaScript. תקן ישירות בקובץ ודווח על כל תיקון.
> שים לב במיוחד לנכונות פדגוגית: שכל עובדה לשונית נכונה ושכל תשובה
> מסומנת-כנכונה אכן נכונה.

למה סוכן נפרד? היוצר "עיוור" לשגיאות של עצמו. בסבב התיקונים של שיעורים
49–59 נמצאו עשרות שגיאות שעברו את היוצר — כולל תוכן פדגוגי שגוי.

### שלב 4 — בדיקה אוטומטית
```
python3 "_system/verify_lesson.py" lessonNN_*.html
```
בודק: HTML תקין, JavaScript תקין, קטע כתיבה אחד, עיצוב הסדרה, ניגודיות
צבעים, שגיאות עברית מוכרות, מספור אחיד, קישורי ניווט, placeholders שנשכחו.
אם נמצאו בעיות — לתקן ולהריץ שוב עד ✅.

### שלב 5 — עדכון רישומים (דקה)
1. הוסיפו את השיעור לטבלה ב-`curriculum.md` וסמנו את הנושא ככוסה.
2. אחרי שבן עושה את השיעור — עדכנו את `ben_progress.md`:
   ענה נכון ברוב השאלות לבד → ✅ · התקשה → 🔁 + הערה ביומן.

## עקרונות פדגוגיים קבועים

- שפה ברמת כיתה ד׳: משפטים קצרים, מילים מוכרות + 6–10 מילים חדשות לשיעור.
- כל כלל דקדוק מנוסח בפשטות + טבלה + דוגמאות + יוצאי דופן נפוצים.
- חזרה מרווחת: נושא נלמד → חיזוק אחרי 10–15 שיעורים בסיפור והקשר חדשים.
- משחק שונה בכל שיעור (לפי הנחיות הפרויקט) — המנוע קבוע, הסצנה מתחלפת.
- שילוב שירים וסיפורים מוכרים מחלק ג של תכנית הלימודים — לפחות כל שיעור שלישי.
