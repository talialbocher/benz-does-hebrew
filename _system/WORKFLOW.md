# תהליך יצירת שיעור חדש — מדריך עבודה

המטרה: שיעורים עקביים, נכונים פדגוגית וללא שגיאות, שמעבירים את בן **בהדרגה
לרמת כיתה ה׳ מלאה ולקריאה ללא ניקוד**.
העיקרון: **שלבים נפרדים, כל שלב עם "עיניים טריות"** — לא סוכן לכל קטע בשיעור,
אלא סוכן יוצר אחד + סוכן מגיה נפרד + בדיקה אוטומטית.

## סדרת כיתה ה׳ (החל מעכשיו)

שיעורים חדשים נשמרים בתיקיית `5thGrade/`, בהמשך למספור הקיים שם
(`lesson01`, `lesson02` כבר קיימים — הבא הוא `lesson03`).

שלושה שינויים קבועים לעומת הסדרה הקודמת:

1. **רמת כיתה ה׳** — טקסטים ארוכים ועשירים יותר, שאלות הסקה ופרשנות לצד
   שליפה, ואוצר מילים ברמת כיתה ה׳.
2. **קטע הקריאה = יצירה מוכרת, עם גיוון וכלל רוטציה** — כל שיעור נבנה סביב
   יצירה קצרה מפורסמת. **סדר עדיפות:**
   1. **שיר מוכר בנחלת הכלל** (יוצר/ת שנפטר/ה לפני 70+ שנים — ביאליק, רחל,
      טשרניחובסקי ואחרים) — **רק אם יש טקסט מאומת** במאגר בחלק ג ב-`curriculum.md`
      (או שהסוכן מצליח לאמת טקסט מדויק ממקור אמין באותה הרצה). לצטט במדויק
      ולציין שם היוצר/ת.
   2. **סיפור עם מוכר מרחבי העולם** (איזופוס, אחי גרים, אנדרסן, אלף לילה
      ולילה, סיפורי חכמי חלם, אגדות מאסיה/אפריקה/אמריקה הלטינית וכו') —
      מעובד/מסופר מחדש, לא ציטוט מדויק. **ברירת המחדל** כשאין טקסט שיר מאומת
      (ראו סעיף 4 למטה) — עדיף על אגדת חז"ל נוספת.
   3. **אגדת חז"ל / סיפור תנ"כי מעובד** — **בשימוש מדוד בלבד: לכל היותר שיעור
      אחד מכל שלושה שיעורים רצופים** בסדרת כיתה ה׳. לפני שבוחרים אגדת חז"ל,
      לבדוק בטבלה בחלק א2 ב-`curriculum.md` מה היו סוגי קטעי הקריאה בשני
      השיעורים הקודמים בסדרה — אם אחד מהם כבר היה אגדת חז"ל/סיפור תנ"כי,
      **אסור** לבחור שוב אגדת חז"ל והשיעור הזה חייב להיות שיר או סיפור עם.
   4. **אם השיר הרצוי אין לו טקסט מאומת** (הסוכן לא בטוח בניסוח המדויק,
      ואין גישה לאימות באינטרנט באותה הרצה) — **אין לנחש את הטקסט ואין
      להחליף באגדת חז"ל כברירת מחדל**. לעבור לסיפור עם מוכר (סעיף 2), או
      לבחור שיר אחר מהמאגר שיש לו טקסט מאומת.

   מאגר מומלץ מלא (שירים עם סטטוס אימות, וסיפורי עם מוכנים לשימוש): חלק ג
   ב-`curriculum.md`. **המאגר ממתין לבדיקה חד-פעמית של טלי** — ראו הערה
   בראש חלק ג. ליצירה שעדיין מוגנת בזכויות יוצרים — קטע קצר בלבד, לא ציטוט מלא.
3. **מעבר הדרגתי לקריאה ללא ניקוד** — לפי הטבלה הבאה, לפי מספר השיעור
   בסדרת כיתה ה׳:

| שיעורים | מדיניות ניקוד |
|---------|----------------|
| 1–2 (קיימים) | ניקוד מלא |
| 3–7 | ניקוד רק ב: היצירה המצוטטת, מילים חדשות, ומילים קשות/דו-משמעיות |
| 8–12 | ניקוד רק ב: היצירה המצוטטת ומילים חדשות (באוצר המילים) |
| 13 ואילך | ללא ניקוד, חוץ מהיצירה המצוטטת (אם המקור מנוקד) ומילה בודדת דו-משמעית במידת הצורך |

בכל מקום שבו כן מופיע ניקוד — הוא חייב להיות נכון ומלא באותה מילה.

## קבצי המערכת (בתיקייה `_system`)

| קובץ | תפקיד |
|------|--------|
| `curriculum.md` | מפת הנושאים — מה כוסה ומה הבא בתור |
| `ben_progress.md` | מעקב אישי — איפה בן חזק ואיפה צריך חיזוק |
| `lesson_template.html` | תבנית קבועה: עיצוב, מבנה, מנוע משחקים, מטלת כתיבה |
| `proofread_checklist.md` | צ׳ק-ליסט לסוכן ההגהה |
| `verify_lesson.py` | בדיקה טכנית אוטומטית |

## השלבים

### שלב 1 — בחירת נושא (דקה)
פתחו את `curriculum.md` ואת `ben_progress.md`. בחרו:
- נושא חדש מחלק ב של תכנית הלימודים, **או**
- שיעור חזרה לנושא שמסומן 🔁 (דורש חיזוק).
כלל אצבע: על כל 3–4 נושאים חדשים — שיעור חזרה אחד.

### שלב 2 — יצירת השיעור (סוכן יוצר)
פרומפט מוכן (להעתיק לשיחה חדשה / לסוכן):

> צור שיעור עברית לכיתה ה׳ מספר NN בנושא [נושא] לפי התבנית
> `_system/lesson_template.html`. קרא קודם את `_system/curriculum.md`
> (להקשר ולרצף) ואת השיעור הקודם בתיקיית `5thGrade/` (לקישורי הניווט).
> דרישות: קטע הקריאה הוא שיר או סיפור קצר מפורסם (עדיפות לנחלת הכלל —
> ראה חלק ג ב-curriculum.md), מצוטט במדויק עם שם היוצר/ת, וכל השיעור
> נבנה סביבו; מדיניות הניקוד לפי טבלת המעבר ב-WORKFLOW.md בהתאם למספר
> השיעור; פלטת צבעים ייחודית; סצנה ויזואלית מקורית לכל
> משחק (דרך onCorrectComp/onCorrectGram); קטע כתיבה אחד;
> 5–6 שאלות הבנה (כולל שאלות הסקה) + 6–8 שאלות דקדוק; אסור להשאיר
> {{placeholders}}. שמור כ-`5thGrade/lessonNN_shem_beanglit.html`.

חשוב: הסוכן היוצר כותב הכל יחד — היצירה המצוטטת מכתיבה את אוצר המילים, השאלות והמשחקים.

### שלב 3 — הגהה (סוכן נפרד, קונטקסט נקי!)
לפתוח שיחה חדשה או תת-סוכן שלא ראה את תהליך היצירה:

> אתה מגיה מומחה לעברית ולניקוד. עבור על הקובץ `5thGrade/lessonNN_*.html`
> לפי הצ׳ק-ליסט `_system/proofread_checklist.md`. בדוק **כל** טקסט עברי,
> כולל מחרוזות בתוך ה-JavaScript. תקן ישירות בקובץ ודווח על כל תיקון.
> שים לב במיוחד לנכונות פדגוגית: שכל עובדה לשונית נכונה ושכל תשובה
> מסומנת-כנכונה אכן נכונה; שהציטוט מהיצירה המוכרת מדויק ושם היוצר/ת
> מצוין; ושמדיניות הניקוד תואמת את טבלת המעבר ב-WORKFLOW.md —
> כל ניקוד שכן מופיע חייב להיות נכון.

למה סוכן נפרד? היוצר "עיוור" לשגיאות של עצמו. בסבב התיקונים של שיעורים
49–59 נמצאו עשרות שגיאות שעברו את היוצר — כולל תוכן פדגוגי שגוי.

### שלב 4 — בדיקה אוטומטית
```
python3 "_system/verify_lesson.py" 5thGrade/lessonNN_*.html
```
בודק: HTML תקין, JavaScript תקין, קטע כתיבה אחד, עיצוב הסדרה, ניגודיות
צבעים, שגיאות עברית מוכרות, מספור אחיד, קישורי ניווט, placeholders שנשכחו.
אם נמצאו בעיות — לתקן ולהריץ שוב עד ✅.

### שלב 5 — עדכון רישומים (דקה)
1. הוסיפו את השיעור לטבלה ב-`curriculum.md` וסמנו את הנושא ככוסה.
2. אחרי שבן עושה את השיעור — עדכנו את `ben_progress.md`:
   ענה נכון ברוב השאלות לבד → ✅ · התקשה → 🔁 + הערה ביומן.

### שלב 6 — שמירה ב-GitHub (חובה!)
לאחר ✅ בשלב 4 ועדכון הרישומים בשלב 5, יש לשמור את השיעור בריפו:
```
git add 5thGrade/lessonNN_*.html _system/curriculum.md _system/ben_progress.md
git commit -m "Add lessonNN: [נושא]"
git push
```
אין לסיים את תהליך יצירת השיעור בלי commit + push. אם ה-push נכשל
(למשל נעילת .git/index.lock מ-GitHub Desktop פתוח) — לבדוק אם יש תהליך git
פעיל בפועל לפני הסרת הנעילה, ולנסות שוב.

## עקרונות פדגוגיים קבועים

- שפה ברמת כיתה ה׳: טקסטים עשירים יותר, 6–10 מילים חדשות לשיעור.
- כל כלל דקדוק מנוסח בפשטות + טבלה + דוגמאות + יוצאי דופן נפוצים.
- חזרה מרווחת: נושא נלמד → חיזוק אחרי 10–15 שיעורים בטקסט והקשר חדשים.
- משחק שונה בכל שיעור (לפי הנחיות הפרויקט) — המנוע קבוע, הסצנה מתחלפת.
- קטע הקריאה בכל שיעור: עדיפות לשיר מוכר בנחלת הכלל עם טקסט מאומת, אחר כך
  סיפור עם מוכר מרחבי העולם; אגדת חז"ל/סיפור תנ"כי לכל היותר שיעור אחד
  מכל שלושה (ראו כלל הרוטציה וסדר העדיפות בסעיף 2 למעלה, ומאגר מלא בחלק ג
  ב-curriculum.md). ציטוט משיר — במדויק, עם קרדיט לשם היוצר/ת.
- ניקוד: לפי טבלת המעבר ההדרגתי בראש המסמך — היעד הוא קריאה שוטפת ללא ניקוד.
